= Email
:description: Bootstrap path for org email — human vs product lanes, provider matrix, DMARC, and setup how-tos. Concept pages live in General Knowledge.

Email is the densest Business Bootstrap area: **human correspondence** and **product messaging** are different jobs. Start with the lane split, then pick providers and escalate DMARC.

This page is the **bootstrap path**. The explanation and reference material (what Cloudflare Routing is and is not, DMARC theory, provider comparison) is canonical in **General Knowledge** and linked below rather than copied here.
