= Stack map
:description: At-a-glance support-systems stack — email, scheduling, design, vault, chat, org infra, funding — with links into each capability area.
:navtitle: Stack map

Short map of **support systems** early organizations usually need besides product code. Each row opens a capability area with room for explanation, how-to, and interconnect articles. Per-org wiring stays in that org's `infra` and product docs. Which rows you actually stand up depends on xref:defaults-by-org-stage.adoc[org stage].

**Forge identity first (optional fast path):** xref:tutorials/fast-org-bootstrap.adoc[Fast org bootstrap] — About, `.github` profile, site, docs hub. This table stays the IT stack.

== Stack

[cols="1,2,2",options="header"]
|===
| Job | Default lean path | Area

| Human vs product email
| ZeptoMail / Resend / Customer.io lane split
| xref:email/index.adoc[Email]

| Scheduling / booking pages
| **Cal.com** hosted for SLA + orgs; **Cal.diy** when you self-host MIT community edition
| xref:scheduling/index.adoc[Scheduling] · xref:scheduling/explanation/cal-com-and-cal-diy.adoc[Cal.com and Cal.diy]

| Product / brand design (Figma-class)
| **Penpot** (open file format, self-host or cloud); Figma when partners require it
| xref:design/index.adoc[Design] · xref:design/explanation/penpot.adoc[Penpot]

| Human + machine secrets vault
| **Bitwarden** cloud (or official self-host for compliance); **Vaultwarden** for tiny self-host
| xref:vault/index.adoc[Vault] · xref:vault/explanation/bitwarden-and-vaultwarden.adoc[Bitwarden and Vaultwarden]

| Team chat / ops bots
| Hosted Slack/Discord until seat cost or residency bites; then **Mattermost** on a real VPS (not shared hosting) with optional R2/B2 offload
| xref:chat/index.adoc[Chat] · xref:chat/explanation/mattermost-self-host.adoc[Mattermost self-host]

| Org DNS + platform IaC
| Pulumi TypeScript org `infra` repo; member-only static hosts behind Cloudflare Access
| xref:infra/index.adoc[Org infra] · xref:explanation/org-infra-repo-pattern.adoc[Org infra repo pattern] · xref:general-knowledge::how-to/cloudflare-access-static-site.adoc[Access how-to]

| Fund OSS maintenance / infrastructure
| GitHub Sponsors and/or Open Collective (fiscal host); grants when the work is public-good scoped — see landscape. On-site: show balance + floor/goal (Nonprofit Resources guide).
| xref:funding/index.adoc[Funding] · xref:funding/explanation/oss-funding-landscape.adoc[OSS funding landscape] · xref:funding/explanation/donation-ask-ideas.adoc[Donation ask ideas]
|===

== What this hub is not

* Not a product partner marketplace (POS, delivery marketplaces, etc.).
* Not a full developer toolchain — see xref:general-knowledge::reference/recommended-tools.adoc[Recommended tools].
* Not AI-studio bootstrap (Cursor skills / MCP / agent rules) — that sibling path is xref:general-knowledge::explanation/infrastructure/vibe-coding-bootstrap.adoc[Vibe coding bootstrap]; stage defaults still remind you during solo / shipping.
* Not a mandate to self-host everything.
