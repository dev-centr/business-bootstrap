= 2026-08-12 — Access on member hostnames

Org infra now points at the general-knowledge pattern for privatizing static sister docs:

* Keep Antora (or any static generator)
* Cloudflare Access on the custom domain **and** `*.pages.dev`
* Identities in GitHub org / Google / one-time PIN — not Cloudflare dashboard users
* GitHub org membership is asked at login (`GET /user/orgs`); Access does not keep a roster. See general-knowledge xref:general-knowledge::explanation/infrastructure/access-in-front-of-static-sites.adoc#how-github-org-membership[How Cloudflare learns GitHub org membership].
