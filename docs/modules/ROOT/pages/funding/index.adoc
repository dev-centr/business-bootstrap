= Funding
:description: How open source projects and early orgs raise money without making every sponsor a customer or a boss.
:navtitle: Funding

Early products need **cash for maintenance**, not only cloud credits for demos. This area maps the common ways open source work gets funded — especially channels that let companies support infrastructure **without** negotiating one-off contracts with each maintainer.

This is an orientation map, not a live grant calendar. Programs open and close; verify eligibility on the official pages before you apply.
