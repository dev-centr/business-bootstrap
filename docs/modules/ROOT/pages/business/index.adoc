= Business topics (ops beyond pure product engineering)
:description: Where non-engineering business ops live while DevCentr remains the docs hub.
:navtitle: Business overview

DevCentr does not run a separate “business resources” Antora site. **Business Bootstrap** is the home for founder/ops topics that are not pure software-engineering Reference.

== What belongs here

* Email, scheduling, design tooling, password vaults, team chat
* Org-level `infra` (DNS, shared platform hosts)
* Funding for open source work and infrastructure (fiscal hosts, grants, sponsorships)
* Stage defaults and vendor stack maps (bootstrap steps differ by maturity)
* Gotchas that are business-process constraints (personal Gmail, free Cloudflare Routing, team pricing traps)

== What belongs in General Knowledge

* Developer IaC mechanics, shells, toolchains, secrets distribution patterns
* Product architecture essentials
* Reference checklists for shipping software
* **AI studio / vibe coding bootstrap** (Cursor skills, MCP, agent rules) — often done in the same weeks as early BB, but not an org-IT capability area here. Start: xref:general-knowledge::explanation/infrastructure/vibe-coding-bootstrap.adoc[Vibe coding bootstrap]

Cross-link freely; do not duplicate long procedures in both places.
