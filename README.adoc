== About The Project

Product-agnostic **support-systems hub** for tech companies: email (human vs product), scheduling (Cal.com / Cal.diy), design (Penpot), secrets vaults (Bitwarden / Vaultwarden), team chat (Mattermost self-host when stage demands it), open source funding (fiscal hosts, grants, sponsorships), DMARC, org-level IaC (`infra` repos), and light ITIL-shaped service catalog naming. Organized by capability area and **org stage** so each topic can grow tutorials, how-tos, and interconnect articles without a second Antora component.

Organized with Diátaxis (tutorials, how-to, reference, explanation). Aggregated on link:https://docs.devcentr.org[docs.devcentr.org].
